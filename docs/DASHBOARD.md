# Dashboard Page

This document provides an overview of the dashboard page, including its features and functionalities.

## Features

- Progress Tracking: View your progress across different modules and tests.
- Test Results: Access detailed results of your completed tests.
- Score Analytics: Analyze your performance with charts and graphs.
- Recent Activity: See your recent activities and updates.

Task 2: Integrate with /test-bay backend to fetch and display real-time results.

Task 3: In results page, ensure the user gets a summary of their test performance including:
- Total Questions
- Questions Correct
- Questions Incorrect

- Integrate AI to provide feedback on incorrect answers and suggest resources for improvement
