# ThrustLab Core Color Palette

This document contains the primary hex color codes used for each section (learning zone) of the ThrustLab platform, as defined in the styling system.

## Zone Accent Colors
These are the primary identity colors used for headers, borders, and active states within each specific zone.

| Section | Hex Code | Description |
| :--- | :--- | :--- |
| **Hangar Zone** | `#1B3558` | Deep Navy Blue |
| **Turbofan Engine** | `#CE5508` | Industrial Orange |
| **Overhaul Station** | `#5DA8CB` | Sky Blue |
| **Test Bay** | `#8461f4` | Dawn Purple |

## Background & Gradient Colors
These colors form the foundation of the UI and are used in gradients across the homepage and main layouts.

| Name | Hex Code | Usage |
| :--- | :--- | :--- |
| **Navy (Primary BG)** | `#223A5E` | Navigation, Homepage Hero, Gradients |
| **Orange (Turbofan Base)**| `#D75E2E` | Gradients, Action Buttons |
| **Light Blue (Overhaul Base)**| `#74B3D4` | Gradients, UI Elements |
| **Purple (Test Bay Base)**| `#9B8AA4` | Gradients, Background Overlays |

## UI Identity Colors
Universal colors used for feedback and common interface elements.

| Name | Hex Code | Usage |
| :--- | :--- | :--- |
| **UI Yellow** | `#FFD966` | Accents, Highlights, Hover states |
| **UI Light Blue** | `#87CEEB` | Links, Secondary accents |
| **UI Dark Teal** | `#0A2F35` | Tooltips, Modal backgrounds |
| **Cyan Accent** | `#00CED1` | Animated gradients |

> [!NOTE]
> All colors are defined as CSS variables in `src/app.css` for consistent usage throughout the application.
