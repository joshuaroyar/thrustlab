# Navbar

The navbar is designed to provide easy access to the main sections of the ThrustLab platform, ensuring users can quickly navigate to educational zones, their profile, and other essential features.

The navigation bar includes the following links:

Left:
    ThrustLab (logo) - links to Home

Right:
    - [Hangar Zone](/hangar-zone)
    - [Turbofan Zone](/turbofan-zone)
    - [Overhaul Station](/overhaul-station)
    - [JAJA](/jaja)
    - [Sign Up](/sign-up)
    - [Log In](/login)
    - [Contact Us](/contact-us)
    - [Test Bay](/test-bay) (Protected)
    - [Dashboard](/dashboard) (Protected)
    - [Profile](/profile) (Protected)
    - [Log Out](/logout) (Protected)

The navbar is responsive and adapts to different screen sizes, ensuring a seamless user experience across devices.
