# ThrustLab

ThrustLab is a dynamic web-based educational platform that empowers students and instructors to engage with complex engineering models through real-time interactive simulations, all directly in the browser. ThrustLab transforms traditional STEM learning by enabling hands-on assembly and disassembly of 3D models, guided tutorials for each part, and instant assessment feedback—no separate apps required.

## Key features

- Interactive 3D model manipulation: assemble, disassemble, explore engineering designs in real time.

- Guided tutorials: access contextual help and rich content while interacting with each part of a model.

- Instant assessment feedback: take quizzes and see performance analytics to track individual learning progress.

- Instructor tools: securely manage classes, monitor student results, and assign collaborative activities.

- Full browser support: accessible from any device, with responsive layouts for desktop, tablet, and mobile.

ThrustLab is designed to make immersive, scalable, and accessible STEM education possible for learners and educators everywhere.
